# 📊 Data Analysis Study
데이터 분석을 위한 파이썬 라이브러리(NumPy, Pandas) 학습 및 실습 코드 저장소입니다. <br>
공식 문서를 기반으로 핵심 개념을 직접 타이핑하며 실습한 기록을 담고 있습니다. ✍️

## 📚 학습 내용
- **NumPy** ✅ 완료   
    - 배열 생성, 연산, 인덱싱, 형태 변환, 복사 개념, 고급 인덱싱, 팁&트릭

- **Pandas** 📋 학습 예정

## 🎯 학습 목표

- 실습 코드와 주석으로 개념을 정확히 이해하고 정리합니다.
- 데이터 분석 프로젝트에 적용할 수 있는 실력을 키웁니다.

## 📝 학습 원칙
